# Santander-Tech+
Repositório do curso do programa Santander Tech+, uma parceria entre o Santander e a Ada.

## Estrutura de Pastas

- **Análise Exploratória de Dados/**  
  Notebooks sobre análise exploratória, visualização de dados, tratamento de outliers e agrupamentos.

- **Banco de dados/**  
  Materiais e exemplos práticos relacionados a bancos de dados, incluindo scripts SQL e exercícios.

- **Case - analytics no mercado de vinhos/**  
  Estudos de caso aplicados ao mercado de vinhos, com análise exploratória, preparação de dados e modelos de machine learning.

- **Case 2 - Insights de vendas no mercado de bicicletas/**  
  Case focado em análise de vendas e geração de insights no setor de bicicletas.

- **Case 3 - vendas de video-game/**  
  Case sobre análise de vendas no mercado de video-games, com dados históricos e gráficos.

- **Desmistificando dados/**  
  Notebooks explicativos sobre conceitos fundamentais de dados, tratamento, normalização e visualização.

- **Entendendo as informações geradas/**  
  Conteúdos sobre interpretação e análise das informações extraídas dos dados processados.

- **Python/**  
  Notebooks introdutórios e intermediários sobre Python, cobrindo variáveis, estruturas de dados, manipulação de arquivos e funções.

- **Simplificando tarefas - GenIA na prática!/**  
  Exemplos práticos de uso de inteligência artificial generativa para simplificação de tarefas do dia a dia.

- **disciplinas.csv**  
  Arquivo com a lista de disciplinas.

## Como utilizar

1. Clone este repositório.
2. Navegue pelas pastas para acessar os notebooks e materiais de estudo.
3. Execute os notebooks em ambiente Jupyter ou Google Colab para acompanhar os exemplos e exercícios.
